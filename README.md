## Descripción

Agenda diaria es una extensión para Mozilla Firefox basada
en «El mosaico del tiempo», reloj interactivo desarrollado
en la PR1 de la asignatura.

La aplicación integra la representación visual del tiempo
con la planificación y gestión de citas diarias.

## Funcionalidades

- Reloj interactivo formado por 24 piezas cromáticas.
- Representación visual de minutos y segundos.
- Navegación entre fechas.
- Creación, consulta y edición de citas.
- Clasificación de citas por categorías.
- Gestión de citas completadas, canceladas y eliminadas.
- Indicador de progreso diario.
- Almacenamiento local de las citas.

## Instalación en Firefox

1. Descargar el repositorio desde Code > Download ZIP.
2. Descomprimir el archivo.
3. Abrir Mozilla Firefox.
4. Introducir about:debugging en la barra de direcciones.
5. Seleccionar «Este Firefox».
6. Pulsar «Cargar complemento temporal».
7. Seleccionar el archivo manifest.json.
8. Abrir Agenda diaria desde el menú de extensiones.

La instalación es temporal y deberá repetirse al reiniciar
Firefox.
